# SmartLab360 🔬

## QR-Based Laboratory Equipment Booking, Tracking and Maintenance Management System

SmartLab360 is a Java Full Stack web application designed to manage laboratory equipment, equipment booking, QR-based equipment tracking, maintenance requests, and notifications in a centralized system.

## 🚀 Features

- 🔐 JWT-based Authentication
- 👨‍🎓 Student and Admin Role Management
- 🧪 Laboratory Equipment Management
- 📅 Equipment Booking
- 📱 QR Code-based Equipment Access
- 🔧 Maintenance Request Management
- 🔔 Real-time Application Notifications
- ✅ Booking Approval / Rejection
- 🛠️ Maintenance Status Tracking
- 📊 Dashboard
- 🔒 Role-Based Backend Security

## 🛠️ Technologies Used

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

### Frontend
- HTML
- CSS
- JavaScript

### QR Code
- ZXing

## 👥 User Roles

### Student
- Login / Register
- View laboratory equipment
- Book equipment
- View booking history
- Report equipment problems
- Track maintenance requests
- Receive notifications

### Admin
- Manage equipment
- View all bookings
- Approve / reject bookings
- View maintenance requests
- Update maintenance status
- Receive system information
